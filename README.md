## Usage

All commands go through `main.py` with two sub-commands: `train` and `test`.

### Part 1 — train all experiments

Runs exact-return forecasting (b), rolling-average forecasting (c), and turning-point detection (d):

```powershell
python main.py train --part 1 --experiment all
```

### Part 1 — train a single experiment

```powershell
python main.py train --part 1 --experiment returns --model lstm
python main.py train --part 1 --experiment rolling_avg --model gru
python main.py train --part 1 --experiment turning_point --model bilstm
```

### Part 2 — train communication protocol

```powershell
python main.py train --part 2
```

### Evaluate a saved checkpoint

```powershell
python main.py test --part 1 --experiment returns --model lstm
python main.py test --part 2 --model communication
```

Optional flags for both parts:

| Flag | Description |
|------|-------------|
| `--epochs` | Override number of training epochs |
| `--batch-size` | Override batch size |
| `--learning-rate` | Override learning rate |
| `--seed` | Random seed (default: 42) |
| `--results-dir` | Custom output directory |
| `--checkpoint` | Checkpoint path for `test` |

## Part 1 overview

| Section | Task | Models | Metric |
|---------|------|--------|--------|
| (b) | Exact d-day return forecasting | LSTM, GRU | MSE / MAE |
| (c) | Rolling-average return forecasting | LSTM, GRU | MSE / MAE |
| (d) | Buy/pass turning-point detection | BiLSTM, BiGRU | Accuracy, F1 |

**Data:** AAPL, MSFT, GOOGL daily OHLC (Jan 2020 – Dec 2025) via `yfinance`.

**Split (chronological):**
- Train: Jan 2020 – Jul 2024
- Val: Aug – Dec 2024
- Test: Jan 2025 – Dec 2025

**Defaults:** lookback `T=20`, horizons `d=1..5`, AdamW, MSE loss, early stopping (patience=5).

## Part 2 overview

Transformer-based transmitter and receiver learn a communication protocol over:
- **Forward channel:** AWGN with σ² = 0.25
- **Feedback channel:** noiseless relay of received symbols
- **Rounds:** T = 4
- **Messages:** {1,…,8}⁴ = 4096 total

**Defaults:** batch size 256, up to 200 epochs, early stopping (patience=15), cross-entropy loss.

## Configuration

Edit defaults there or override via CLI flags.

## Implementation notes

- **Part 1(d) threshold:** The assignment specifies γ = 1.1, but that yields zero buy labels on S&P 500 data. We use γ = 0.011 (1.1% return); see `StockDataParams.turning_point_gamma` in `parameters.py`.
- **Part 1 data:** Stock CSVs are cached in `data/` on first download.
- **Part 2 feedback:** Implemented as a simple relay of noisy received symbols (assignment Hint 1).
